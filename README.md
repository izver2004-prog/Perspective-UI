Perspective UI

A new perspective on your Minecraft inventory.

Perspective UI is a client-side Minecraft mod that transforms inventory and container screens into a more immersive 3D interface.

Features

- 3D Perspective — adds depth to inventory and container screens.
- Player Preview — displays your character on the left side of the interface.
- Mouse Interaction — interface movement responds to your mouse.
- Smooth Animations — animated screen opening and closing.
- Client-Side — designed to work on the client without requiring server-side installation.

Compatibility

- Minecraft: 26.1.2
- Mod Loader: Fabric

Installation

1. Install Fabric Loader for Minecraft 26.1.2.
2. Open the "Releases folder" (https://github.com/izver2004-prog/Perspective-UI/tree/main/Releases).
3. Download the appropriate ".jar" file.
4. Place the file into your Minecraft "mods" folder.
5. Launch Minecraft using the Fabric profile.
